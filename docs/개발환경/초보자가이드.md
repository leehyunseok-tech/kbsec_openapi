# 초보자 가이드 — 이 프로젝트가 뭐고, 어떻게 돌아가나요?

> 프로그래밍을 전혀 모르는 사람도 이 프로젝트를 이해할 수 있도록 쓴 문서입니다.
> 그림(다이어그램)으로 구조를 보고 싶으면 [프로젝트구조.md](프로젝트구조.md)를,
> 명령어 사용법은 [command_summary.md](command_summary.md)를 함께 보세요.

## 1. 이 프로그램은 무엇인가요?

한 줄로 말하면 **"KB증권 계좌로 주식을 조회하고 사고파는 비서 프로그램"** 입니다.

- 증권사 앱을 열지 않고도, **텔레그램 메시지**나 **컴퓨터 명령창(터미널)**,
  **웹 브라우저**로 "삼성전자 지금 얼마야?", "삼성전자 10주 사줘" 같은 일을 시킬 수 있습니다.
- 말로 시키면(자연어) AI(Claude)가 알아듣고 정확한 명령으로 바꿔준 뒤,
  **실행 전에 반드시 사용자에게 "이렇게 실행할까요?" 하고 확인**을 받습니다.
- "주가가 5% 떨어지면 자동으로 팔아줘(손절)" 같은 **자동매매**도 설정해두면
  프로그램이 계속 지켜보다가 조건이 되는 순간 대신 주문해 줍니다.

⚠️ **중요**: 이 프로젝트는 모의투자(연습 계좌)가 아니라 **실제 계좌·실제 돈**으로
동작합니다(KB증권이 아직 모의투자 환경을 제공하지 않음). 매수/매도 명령은 진짜
주문이 나가니 항상 확인 메시지를 잘 읽고 승인하세요.

## 2. 꼭 알아야 할 용어 6개

| 용어 | 쉬운 설명 |
|---|---|
| **API** | 프로그램끼리 대화하는 창구. "KB증권 API를 호출한다" = 우리 프로그램이 KB증권 서버에 "삼성전자 현재가 알려줘" 같은 요청을 정해진 형식으로 보낸다는 뜻. |
| **REST** | API 요청을 보내는 방식의 하나. 편지 주고받기처럼 **요청 1번 → 응답 1번**으로 끝난다. (전화 통화처럼 계속 연결해두는 방식은 '웹소켓'인데, KB증권은 제공하지 않는다.) |
| **토큰(access token)** | API를 쓰기 위한 **임시 출입증**. 프로그램 시작 후 로그인하면 발급받고, 이후 모든 요청에 이 출입증을 함께 보낸다. |
| **앱키(client_key/secret)** | KB증권 개발자 사이트에서 발급받는 **내 계정의 열쇠**. 이걸로 토큰을 발급받는다. 절대 남에게 보여주거나 인터넷에 올리면 안 된다. |
| **폴링(polling)** | "몇 초마다 한 번씩 계속 물어보기". 실시간 연결(웹소켓)이 없으므로, 자동매매는 주기적으로 "지금 가격 얼마야?"를 반복 조회하는 방식으로 감시한다. |
| **핸들러(handler)** | 명령 하나를 처리하는 코드 뭉치(함수). 예: `/buy` 명령이 오면 `buy_command.py` 안의 핸들러가 실행된다. |

## 3. 세 가지 사용 방법 (같은 두뇌, 다른 입구)

이 프로그램은 입구가 3개지만 **두뇌(명령 처리 코드)는 하나**입니다.
어느 입구로 들어와도 똑같이 동작합니다.

| 입구 | 실행 방법 | 언제 쓰나 |
|---|---|---|
| **터미널** | `uv run python -m src.run.terminal` | 개발/테스트할 때 기본. 텔레그램 없이 바로 사용 |
| **텔레그램** | `uv run python -m src.run.main` | 평소 운영용. 휴대폰으로 어디서든 명령 |
| **웹** | `uv run python -m src.run.web` 후 브라우저에서 http://localhost:8000 | 화면(버튼/표)으로 보고 싶을 때 |

`manage/run/` 폴더의 `run-terminal.bat`, `run-main.bat`, `run-web.bat`(윈도우) /
`.sh`(맥·리눅스)를 더블클릭/실행해도 됩니다 — 위 명령을 대신 쳐주는 파일입니다.

## 4. 폴더마다 뭐가 들어있나요? (비유로 이해하기)

프로젝트 폴더를 **회사 사무실**이라고 생각해 보세요.

| 폴더 | 비유 | 실제 내용 |
|---|---|---|
| `src/` | **일하는 직원들** | 실제로 실행되는 모든 프로그램 코드 |
| `src/run/` | 안내데스크 | 프로그램 시작점 3개(터미널/텔레그램/웹) |
| `src/commands/` | 업무 담당자들 | 명령 1개당 파일 1개 (`buy_command.py` = 매수 담당) |
| `src/api/` | KB증권 전화 담당 | KB 서버에 요청을 보내는 함수들. **대부분 자동 생성되므로 직접 고치면 안 됨** |
| `src/utils/` | 만능 도구함 | 종목 검색, 자동매매 감시, 로그 기록 등 보조 도구 |
| `src/web/` | 온라인 창구 | 웹 화면 서버와 웹페이지 파일 |
| `config/` | 금고 | API 열쇠 등 비밀 설정. `config.py`는 git에 올라가지 않음 |
| `docs/` | 서류 보관실 | 문서. 일부 문서(AI 규칙, API 명세)는 프로그램이 실행 중에 직접 읽음 |
| `mst/` | 전화번호부 | 전체 종목의 코드↔이름 목록 (예: 삼성전자=005930) |
| `manage/` | 시설 관리팀 | 평소엔 안 쓰고, 데이터를 새로 만들거나 설치할 때만 쓰는 스크립트 |
| `logs/` | 거래 장부 | 자동매매가 체결한 내역이 날짜별 CSV로 쌓임 |

## 5. "삼성전자 10주 사줘"라고 하면 무슨 일이 벌어지나요?

1. **입력 접수** — 텔레그램/터미널/웹 중 한 곳으로 문장이 들어옵니다.
2. **명령어인지 판단** — `/`로 시작하면(예: `/buy 005930 10`) 바로 해당 담당자
   (핸들러)에게 전달합니다. 아니면 자연어로 보고 다음 단계로 갑니다.
3. **AI 번역** — Claude AI가 문장을 읽고 정확한 명령(`buy 삼성전자 10`)으로 바꿉니다.
   이때 AI는 `docs/command_guide_for_ai.md`라는 **규칙 문서**를 참고합니다.
4. **종목코드 확정** — AI가 종목 코드를 추측하게 두지 않고, 프로그램이
   `mst/`의 전화번호부에서 "삼성전자 → 005930"을 **직접 찾아 확정**합니다.
   비슷한 이름이 여러 개면 번호를 골라달라고 물어봅니다.
5. **사용자 확인** — "buy 005930 10 을 실행할까요?" 하고 보여주고, 승인해야만 진행합니다.
6. **주문 실행** — `src/api/order.py`가 KB증권 서버에 주문 요청을 보냅니다.
7. **결과 보고** — 성공/실패 결과를 원래 입구(텔레그램/터미널/웹)로 알려줍니다.

이 흐름의 그림 버전은 [프로젝트구조.md 3절](프로젝트구조.md#3-명령-처리-흐름-핵심-동작)에 있습니다.

## 6. 자동매매는 어떻게 "지켜보나요"?

"조건이 되면 알아서 사고팔기"는 이렇게 동작합니다:

1. 사용자가 감시를 시작합니다 (예: `/trst` 트레일링 스탑, `/gdcrs` 골든크로스 등).
2. 프로그램 안에 **감시 요원(백그라운드 스레드)** 이 하나 생깁니다.
3. 감시 요원은 정해진 주기(폴링)로 KB 서버에 현재가를 물어봅니다.
4. 조건이 충족되는 순간 자동으로 주문을 넣고, `logs/` 장부에 기록하고, 사용자에게 알립니다.
5. 중지 명령을 내리거나 프로그램을 끄면 감시가 멈춥니다.

실시간 연결이 아니라 "몇 초 간격 확인"이므로, 그 사이의 아주 짧은 가격 변화는
놓칠 수 있다는 한계가 있습니다 (KB API에 실시간 웹소켓이 없어서 생기는 제약입니다).

## 7. 처음 실행해보기 (순서대로)

1. **설치** — 프로젝트를 처음 받았다면 `manage/install/install-project.bat`(윈도우)
   또는 `install-project.sh`(맥·리눅스)를 실행합니다. 파이썬/uv/의존성을 알아서 준비해 줍니다.
2. **열쇠 채우기** — `config/config.example.py`를 복사해 `config/config.py`를 만들고,
   KB증권 개발자 사이트에서 받은 앱키, (선택) 텔레그램 봇 토큰, (선택) Claude API 키를
   채웁니다. **이 파일은 절대 공유하지 마세요.**
3. **터미널로 첫 실행** — `uv run python -m src.run.terminal` → `login` 입력 →
   토큰이 발급되면 성공입니다.
4. **간단한 조회부터** — `/srch 005930`(삼성전자 조회), `/report`(계좌 현황) 같은
   **조회 명령**으로 먼저 연습하세요. 매수/매도는 실제 돈이 나가니 마지막에요.

## 8. 절대 하지 말아야 할 것

- ❌ `config/config.py`(열쇠 파일)를 메신저/게시판/git에 올리기
- ❌ `src/api/`의 자동 생성 파일이나 `mst/api/`, `docs/api/api-list.*`를 손으로 고치기
  → 원본을 고치고 `manage/generate/` 스크립트를 재실행해야 합니다 ([manage.md](manage.md) 참고)
- ❌ 확인 메시지를 읽지 않고 매수/매도 승인하기 (실제 주문입니다!)
- ❌ 웹 서버를 `token` 모드(자동 로그인)로 켠 채 외부에 공개하기 — 접속하는 모든
  사람이 내 계좌로 로그인됩니다. `token` 모드는 내 컴퓨터에서만 쓰세요.
