# 슬래시(`/`) 명령어 요약

`/`로 시작해 텔레그램/터미널/웹에서 **AI를 거치지 않고 즉시 실행**되는 명령어 전체
목록입니다. (`/` 없이 입력하면 자연어로 간주되어 Claude가 명령어로 변환한 뒤 확인을
거칩니다 — 그 변환 규칙은 이 문서가 아니라 `docs/command_guide_for_ai.md`가 담당합니다.)

- 세 클라이언트(`src/run/main.py`/`src/run/terminal.py`/`src/web/client.py`) 모두 같은
  `src/commands/*_command.py` 핸들러를 공유하므로 동작은 동일합니다. 여기 예시는 `/`
  접두어 기준(텔레그램/웹)으로 적었습니다 — 터미널에서도 `/` 그대로 입력하면 됩니다.
- 국내 종목은 6자리 코드(`005930`), 해외(미국) 종목은 티커(`IONQ`)를 사용합니다.
  `buy`/`sell`/`srch`는 종목명으로 입력해도 로컬 종목마스터가 코드로 변환해 줍니다
  (예: `/buy 삼성전자 10`).
- 새 명령어를 추가/변경할 때는 이 문서도 함께 갱신하세요(`CLAUDE.md` 필수 규칙 5번은
  `docs/command_guide_for_ai.md`를 가리키지만, 이 문서도 실제 명령어 목록과 어긋나지 않게
  유지해야 합니다).

## 1. 인증 및 상태

### `/login`
KB증권 OAuth2 접근토큰을 발급받아 거래를 시작합니다.

| 사용법 | 설명 |
|---|---|
| `/login real` | 운영환경(실거래)으로 로그인 |

KB증권 개발환경(모의투자)은 아직 제공되지 않아 `dev`는 정상 동작하지 않습니다. 웹
클라이언트는 `/login`을 직접 입력하는 대신 설정 화면(`/settings.html`)에서 앱키를
저장하면 자동으로 로그인됩니다.

**예시**
```
/login real
```

### `/status`
현재 로그인 여부, 거래 환경, 토큰 남은 시간을 확인합니다.

```
/status
```

## 2. 조회

### `/srch`
종목의 현재가·등락률·거래량·PER/PBR 등 기본 정보를 조회합니다. **국내 + 미국 주식 모두 지원.**

```
/srch {종목코드}
```

**예시**
```
/srch 005930        (삼성전자)
/srch IONQ           (미국 아이온큐)
```

### `/rank`
상위 종목 랭킹을 조회합니다.

| 사용법 | 설명 |
|---|---|
| `/rank` | 메뉴 표시 |
| `/rank 1` | 거래대금상위 Top 20 |
| `/rank 2` | 등락률상위 Top 20 |
| `/rank 3` | 거래량상위 Top 20 |
| `/rank 4` | 업종랭킹 |

**예시**
```
/rank 2
```

### `/report`, `/r`
보유종목 현황과 미체결 주문을 조회합니다(둘은 완전히 동일한 명령의 별칭).

```
/report
/r
```

### `/mst`
종목마스터(로컬 파일) 로드 현황을 조회합니다. API 호출 없이 `mst/api/*.mst`만 읽습니다.

```
/mst
```

### `/stcd`
종목명/종목코드 키워드로 검색합니다. 국내는 종목코드 일부로도 검색됩니다.

| 사용법 | 설명 |
|---|---|
| `/stcd {키워드}` | 키워드 검색 |
| `/stcd {키워드1} {키워드2} ...` | 여러 키워드 OR 검색 |

**예시**
```
/stcd 삼성
/stcd 005930
/stcd 카카오 네이버
```

### `/investor`
종목의 투자자별(개인/외국인/기관) 누적 순매수 차트를 이미지로 생성합니다. **국내 전용**
(해외는 KB API에 대응 API가 없음). 텔레그램은 사진으로 전송, 웹/터미널은 이미지 파일
경로를 반환합니다.

```
/investor {종목코드} {개월수}
```

**예시**
```
/investor 005930 3   (삼성전자 최근 3개월)
```

## 3. 매매

### `/buy`
종목을 매수합니다. **국내(6자리 코드) + 미국 주식(티커) 모두 지원.**

| 사용법 | 설명 |
|---|---|
| `/buy {종목코드} {수량}` | 시장가 매수 (미국은 현재가 조회 후 지정가로 제출) |
| `/buy {종목코드} {수량} {지정가}` | 지정가 매수 |
| `/buy {종목코드} max {금액}` | 금액 범위 내 최대 수량 매수 (국내: 원화, 미국: USD) |

**예시**
```
/buy 005930 10                 (삼성전자 10주 시장가)
/buy 005930 5 70000             (삼성전자 5주, 70,000원 지정가)
/buy 005930 max 1000000         (100만원 이내 최대 수량)
/buy IONQ 10                    (아이온큐 10주 시장가)
```

### `/sell`
종목을 매도합니다. **국내(6자리 코드) + 미국 주식(티커) 모두 지원.** 미국 주식은
보유수량 자동조회가 되지 않아 수량을 반드시 명시해야 합니다(전량 매도는 국내 전용).

| 사용법 | 설명 |
|---|---|
| `/sell all` | 보유 전체 종목 시장가 매도 (국내만) |
| `/sell {종목코드}` | 전량 매도 (국내만, 시장가) |
| `/sell {종목코드} {수량}` | 수량 지정 매도 (미국은 현재가 조회 후 지정가로 제출) |
| `/sell {종목코드} {수량} {지정가}` | 지정가 매도 |

**예시**
```
/sell all
/sell 005930
/sell 005930 5
/sell IONQ 3
```

### `/ccl`
미체결 주문을 전체 취소합니다.

```
/ccl pend
```

## 6. API 직접호출 (`docs/api/md` 명세 기반)

명세 문서(`docs/api/md/*.md`)에 등록된 KB API라면 코드나 이름만 알면 바로 실행할 수
있는 범용 명령. 조회 API뿐 아니라 주문 API도 실행 가능하므로 실거래 계좌에서 특히
주의해서 사용하세요.

### `/api`
| 사용법 | 설명 |
|---|---|
| `/api {API코드}` | 해당 API 실행. INPUT 표에서 필수(Y)+선택지가 있는 필드는 번호 선택(대화형), 그 외는 타입(길이)만큼 공백으로 자동 채움 |
| `/api info {API코드}` | 실행하지 않고 어떤 필드가 선택 대상/공백 채움인지 미리보기 |
| `/api list [키워드]` | 코드/API명/업무구분으로 검색 (키워드 생략 시 전체) |

**예시**
```
/api SSQM1801           (보유주식 조회 실행)
/api info SSAM1802      (매수주문의 파라미터 미리보기)
/api list 계좌잔고
```

### `/call`, `/info`, `/list` — 저수준 직접 호출 (터미널/웹 전용)
`/api`보다 한 단계 낮은 저수준 통로. 지정한 필드만 JSON으로 채우고 나머지 INPUT
필드는 전부 타입(길이)만큼 공백으로 자동 채워 요청을 구성합니다.

| 사용법 | 설명 |
|---|---|
| `/call {API코드} ['{JSON}']` | API 호출 |
| `/info {API코드}` | 파라미터(타입/길이/필수여부/선택지) 조회 |
| `/list [키워드]` | 등록 API 코드/이름/업무구분 검색 |

**예시**
```
/call SZQM0771 {}
/call SSAM1801 {"is_cd":"005930","ordr_q":"1","ordr_uprc":"320000"}
/info SSAM1801
```

## 7. 자동매매 (폴링 기반, 09:00~15:30)

KB API에는 실시간 웹소켓이 없어 모두 REST 폴링(`src/utils/monitor_base.py` 기반)으로
동작합니다. 조건검색식 실시간거래(jggs)·VI감시(vi)·테마(theme)·공매도(short/loan)는
KB API에 대응 API가 없어 지원하지 않습니다.

### `/gdcrs` — 골든크로스 자동매수
| 사용법 | 설명 |
|---|---|
| `/gdcrs intv {단기} {장기}` | 이동평균 기간(분봉 개수) 설정 |
| `/gdcrs add {종목코드} {금액}` | 감시 종목 추가 |
| `/gdcrs list` | 감시 목록 조회 |
| `/gdcrs remove {번호}` | 감시 종목 제거 |
| `/gdcrs clear` | 감시 목록 전체 삭제 |

**예시**
```
/gdcrs intv 5 20
/gdcrs add 005930 100000
```

### `/ddcrs` — 데드크로스 자동매도
별도 설정 명령 없이 `/gdcrs intv`의 분봉 주기를 그대로 공유합니다. 보유종목을 대상으로
데드크로스가 감지되면 자동 매도합니다.

```
/ddcrs
```

### `/trst` — 트레일링 스탑
| 사용법 | 설명 |
|---|---|
| `/trst` | 현재 설정 조회 |
| `/trst {하락율} {최소수익률}` | 설정 변경 |

**예시**
```
/trst 3.5 5
```

### `/brk` — 돌파매수 감시
| 사용법 | 설명 |
|---|---|
| `/brk rate {상승률}` | 돌파 기준 상승률 설정 |
| `/brk add {종목코드} {명령어}` | 감시 종목과 돌파 시 실행할 명령 추가 |
| `/brk list` | 감시 목록 조회 |
| `/brk remove {번호}` | 감시 종목 제거 |

**예시**
```
/brk rate 3
/brk add 005930 buy 005930 10
```

### `/wave` — 분할매매
| 사용법 | 설명 |
|---|---|
| `/wave set buy {a} {b} {c} sell {d} {e} {f}` | 매수/매도 파동 조건 설정 |
| `/wave view` | 현재 설정 조회 |
| `/wave add {종목코드} {투자금액}` | 감시 종목 추가 |
| `/wave list` | 감시 목록 조회 |
| `/wave remove {번호}` | 감시 종목 제거 |

**예시**
```
/wave set buy 3 6 2 sell 3 6 2
/wave add 005930 1000000
```

### `/grid` — 그리드 트레이딩
| 사용법 | 설명 |
|---|---|
| `/grid add {종목코드} {기준가} {간격} {주문금액} {최대단계}` | 그리드 감시 추가 |
| `/grid list` | 감시 목록 조회 |
| `/grid remove {번호}` | 감시 제거 |

**예시**
```
/grid add 005930 75000 2 100000 3
```

### `/start`, `/stop` — 자동매매 감시 시작/중단
위 6개 전략(`gdcrs`/`ddcrs`/`trst`/`brk`/`wave`/`grid`) + 보유종목 변경 감지(`hold`)를
공통으로 시작/중단합니다.

| 사용법 | 설명 |
|---|---|
| `/start {stls\|gdcrs\|ddcrs\|trst\|hold\|brk\|wave\|grid}` | 해당 감시 시작 |
| `/stop {stls\|gdcrs\|ddcrs\|trst\|hold\|brk\|wave\|grid}` | 해당 감시 중단 |

**예시**
```
/start trst
/stop grid
```
