## AI 참고 사항

이 문서는 KB증권 OpenAPI 명세서입니다.

**요청 시 주의사항:**
- `dataHeader`에 `ipAddr`(IP주소)와 `macAddr`(MAC주소)를 포함해야 합니다.
- `dataBody`에 필수 파라미터를 모두 포함해야 합니다.

**응답 구조:**
- `dataHeader`: 결과 코드, 메시지, 처리 시간 등 메타 정보
- `dataBody`: 실제 응답 데이터 (배열인 경우 `out2` 등의 키로 포함)

**필드 타입 설명:**
- `C숫자`: 문자열 (숫자는 최대 길이)
- `N숫자`: 숫자
- `P숫자`: 소수점 포함 숫자 (숫자는 소수점 자릿수)
