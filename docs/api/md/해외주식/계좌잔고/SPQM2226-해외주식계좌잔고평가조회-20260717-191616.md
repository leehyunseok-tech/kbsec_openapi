- `dataHeader`에 `ipAddr`(IP주소)와 `macAddr`(MAC주소)를 포함해야 합니다.

**응답 구조:**
- `dataHeader`: 결과 코드, 메시지, 처리 시간 등 메타 정보

**필드 타입 설명:**
- `C숫자`: 문자열 (숫자는 최대 길이)
- `N숫자`: 숫자
- `P숫자`: 소수점 포함 숫자 (숫자는 소수점 자릿수)
