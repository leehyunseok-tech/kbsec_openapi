# Tailscale로 웹 클라이언트 외부 접속하기

집(또는 사무실) PC에 웹 클라이언트(`src/web/`)를 띄워두고, 외출 중 스마트폰이나 다른 컴퓨터에서
그 화면에 접속하고 싶을 때 사용하는 가이드입니다. **Tailscale**은 내 기기들끼리만 연결되는 사설
네트워크(VPN 메시)를 만들어주는 무료 서비스로, 포트포워딩·공인 IP·인증서 발급 같은 복잡한 네트워크
설정 없이 "앱 설치 + 로그인"만으로 끝난다는 점이 이 프로젝트에 가장 잘 맞습니다.

> 💡 **왜 Traefik이나 AWS가 아니라 Tailscale인가?** 이 프로젝트의 목표는 KB증권 OpenAPI를 활용한
> 자동매매 수익화이지, 인프라 구축 자체가 아닙니다. Traefik(리버스 프록시)은 도메인·TLS 인증서·라우팅
> 규칙을 직접 구성해야 하고, AWS는 서버 비용과 보안그룹 관리가 따라옵니다. 둘 다 "여러 사람에게
> 서비스를 공개"할 때는 적합하지만, "나 혼자 내 PC 화면을 밖에서 보고 싶다"는 목적에는 과합니다.
> Tailscale은 이 목적에 필요한 최소한의 설정만 요구합니다. 더 큰 요구(24시간 무중단 운영, 다중 사용자
> 공개 서비스 등)가 생기면 [docs/배포/](README.md)의 다른 방법(Docker/Traefik/AWS, 추후 추가 예정)으로
> 넘어가면 됩니다.

> 🤖 **막히면 AI에게 물어보세요.** 공유기·방화벽 환경은 집집마다 다를 수 있습니다. 이 문서대로 안 될 때는
> Claude Code 같은 AI 코딩 에이전트에게 에러 메시지나 상황을 그대로 붙여넣고 물어보는 것을 권장합니다.

## 개념 정리 (30초 요약)

1. 내 PC(웹 서버를 띄우는 쪽)와 내 스마트폰(접속하는 쪽) 양쪽에 Tailscale 앱을 설치하고 **같은 계정**으로
   로그인합니다.
2. 그러면 두 기기가 서로를 위한 사설 IP(예: `100.x.x.x`)를 하나씩 받아, 마치 같은 집 와이파이에 있는 것처럼
   서로 직접 통신할 수 있게 됩니다. (인터넷 어디에 있든 상관없습니다.)
3. 이 사설 네트워크는 **내 Tailscale 계정에 속한 기기끼리만** 연결됩니다 — 전혀 모르는 사람이 접속할
   방법이 없습니다. 공인 IP 노출도, 포트포워딩도 필요 없습니다.
4. 웹 클라이언트를 이 사설 IP로 접속 가능하게 실행한 뒤, 스마트폰 브라우저에서 `http://100.x.x.x:8000`처럼
   접속하면 끝입니다.

## 사전 준비: Tailscale 계정 만들기

1. https://tailscale.com/ 접속 → **Get started** (또는 로그인 버튼) 클릭
2. Google / Microsoft / GitHub 계정 등으로 로그인 (별도 회원가입 절차 없이 기존 계정 재사용)
3. 무료 플랜(Personal)으로 충분합니다 — 기기 최대 100대, 사용자 3명까지 무료 (2026년 기준, 변동 가능성 있으니
   가입 시 화면의 최신 안내를 확인하세요)

---

## 1단계: 웹 서버를 띄울 PC에 Tailscale 설치

1. https://tailscale.com/download 에서 사용 중인 OS(Windows/macOS/Linux)용 설치 파일을 내려받아 설치합니다.
2. 설치 후 실행하면 로그인 창이 뜹니다 — 위에서 만든 계정으로 로그인합니다.
3. 로그인이 완료되면 시스템 트레이(Windows) 또는 메뉴바(macOS)에 Tailscale 아이콘이 나타나고, 자동으로
   네트워크에 연결됩니다.

### 이 PC의 Tailscale 주소 확인하기

터미널(PowerShell/명령 프롬프트/터미널)에서 다음을 실행합니다:

```bash
tailscale ip -4
```

`100.`으로 시작하는 IP 주소가 출력됩니다 (예: `100.101.102.103`). **이 주소를 메모해두세요** — 스마트폰에서
접속할 때 이 주소를 사용합니다.

> 💡 트레이 아이콘을 클릭해도 같은 주소를 확인할 수 있습니다.

---

## 2단계: 접속할 기기(스마트폰 등)에 Tailscale 설치

1. 스마트폰에서 앱 스토어(Google Play / App Store)에서 **Tailscale** 앱을 설치합니다.
2. 앱을 실행하고 **1단계와 동일한 계정**으로 로그인합니다.
3. 로그인만 하면 별도 설정 없이 자동으로 연결됩니다. (VPN 권한 요청이 뜨면 허용 — Tailscale은 실제로
   기기 VPN 기능을 이용해 사설망을 구성합니다.)

이제 두 기기가 같은 Tailscale 네트워크(tailnet)에 속하게 되어, 서로 직접 통신할 수 있습니다.

---

## 3단계: 웹 클라이언트를 외부에서 접속 가능하게 실행하기

기본적으로 웹 클라이언트는 `127.0.0.1`(내 PC 자기 자신만 접속 가능)에 바인딩됩니다. 다른 기기(스마트폰
포함)에서 접속하려면 `KBSEC_WEB_HOST` 환경변수로 바인딩 주소를 넓혀야 합니다.

### 3-1. 접속 관문(Basic Auth) 먼저 설정하기 (필수 권장)

Tailscale 사설망 안이라도, 같은 tailnet에 여러 기기/사람이 있다면 웹 화면 자체에는 기본적으로 접근
인증이 없다는 점을 기억하세요 (KB 계좌 로그인과는 별개 문제입니다). 외부에서 접속 가능하게 여는 김에
`config/config.py`에 다음을 채워 넣는 것을 권장합니다:

```python
# 웹 클라이언트 접속 관문 (영문/숫자 권장)
web_basic_auth_user = "원하는_아이디"
web_basic_auth_pass = "원하는_비밀번호"
```

(또는 환경변수 `KBSEC_WEB_BASIC_AUTH_USER`/`KBSEC_WEB_BASIC_AUTH_PASS`로 대신 설정해도 됩니다 — 환경변수가
있으면 그쪽이 우선합니다.)

### 3-2. 바인딩 주소를 넓혀서 실행하기

**Windows (PowerShell):**
```powershell
$env:KBSEC_WEB_HOST = "0.0.0.0"
manage\run\run-web.bat
```

**macOS / Linux:**
```bash
KBSEC_WEB_HOST=0.0.0.0 ./manage/run/run-web.sh
```

> ⚠️ `0.0.0.0`은 "이 PC의 모든 네트워크 인터페이스에서 접속을 받는다"는 뜻입니다. 집 공유기에
> 포트포워딩을 설정하지 않은 이상 인터넷 전체에 노출되는 것은 아니며, Tailscale 사설망을 통한 접속만
> 실질적으로 가능합니다. 다만 같은 와이파이(집/회사망)에 있는 다른 기기에서도 PC의 실제 IP로 접속은
> 가능해지므로, **3-1의 Basic Auth 설정을 꼭 함께 켜두세요.**

실행하면 콘솔에 다음과 같은 안내가 보입니다 (환경에 따라 문구는 다를 수 있습니다):

```
웹 클라이언트 실행 중: http://0.0.0.0:8000
```

## 4단계: 외부 기기(스마트폰 등)에서 접속하기

1. 스마트폰에서 Tailscale 앱이 **연결됨(Connected)** 상태인지 확인합니다.
2. 스마트폰 브라우저(Safari/Chrome 등)를 열고 주소창에 다음을 입력합니다:

   ```
   http://100.101.102.103:8000
   ```

   (`100.101.102.103` 부분은 1단계에서 확인한 실제 PC의 Tailscale IP로 바꿉니다. 포트는 기본 `8000`이며,
   `KBSEC_WEB_PORT` 환경변수로 바꾼 경우 그 값을 씁니다.)

3. Basic Auth를 설정했다면 아이디/비밀번호 입력 팝업이 뜹니다 — 3-1에서 정한 값을 입력합니다.
4. 웹 클라이언트 화면이 뜨면 성공입니다! 이후 사용법은 [README.md의 "🌐 웹 클라이언트 사용법"](../../README.md#-웹-클라이언트-사용법)과 동일합니다.

### MagicDNS로 IP 대신 이름 쓰기 (선택)

매번 숫자 IP를 외우기 번거롭다면, Tailscale 관리 콘솔(https://login.tailscale.com/admin/machines)에서
**MagicDNS**를 켜면 IP 대신 `http://내PC이름:8000`처럼 이름으로 접속할 수 있습니다. 관리 콘솔의
**DNS** 탭에서 켤 수 있으며, 켠 뒤에는 각 기기 목록에 표시된 이름(예: `desktop-abc123`)을 그대로 쓰면
됩니다.

## (선택, 심화) HTTPS로 접속하고 싶다면 — `tailscale serve`

포트 번호 없이, 그리고 브라우저에 자물쇠 아이콘(HTTPS)이 뜨는 상태로 접속하고 싶다면 `tailscale serve`를
쓸 수 있습니다. 웹 서버가 실행 중인 상태에서 PC 터미널에 다음을 입력합니다:

```bash
tailscale serve --bg 8000
```

성공하면 `https://내PC이름.tailnet이름.ts.net`처럼 도메인 형태의 HTTPS 주소가 발급되고, 이 주소는
여전히 **같은 tailnet 안에서만** 접속 가능합니다 (외부 공개 아님). 인증서는 Tailscale이 자동으로
발급/갱신하므로 별도 설정이 필요 없습니다. 끄고 싶을 때는 `tailscale serve --bg off`를 입력합니다.

> 이 단계는 필수가 아닙니다 — 3~4단계(IP+포트로 접속)만으로 충분히 목적을 달성할 수 있습니다.

## (선택, 주의 필요) 진짜 외부 공개가 필요하다면 — `tailscale funnel`

`tailscale serve`가 "내 tailnet 안에서만" 접속이라면, `tailscale funnel`은 **Tailscale 계정이 없는
사람도 인터넷에서 접속 가능**하게 진짜로 공개하는 기능입니다. 이 프로젝트는 실거래 자동매매를 다루므로,
Funnel을 켤 경우 **반드시** Basic Auth(3-1단계)를 설정한 상태에서만 사용하고, 가급적 사용 후에는
`tailscale funnel off`로 꺼두는 것을 강력히 권장합니다. 대부분의 사용 목적(나 혼자 확인)은 Funnel 없이
Tailscale 사설망만으로 충분합니다.

## 문제 해결 (FAQ)

### 스마트폰에서 접속이 안 됩니다

- 스마트폰의 Tailscale 앱이 **Connected** 상태인지 확인하세요 (꺼져 있으면 그냥 일반 인터넷으로 나가서
  PC에 닿지 못합니다).
- PC의 웹 서버가 `KBSEC_WEB_HOST=0.0.0.0`으로 실행 중인지 확인하세요 (기본값 `127.0.0.1`로 실행하면
  PC 자기 자신 외에는 아무도 접속할 수 없습니다).
- PC에서 `tailscale status`를 실행해 스마트폰 기기가 목록에 나타나는지 확인하세요.
- Windows 방화벽이 파이썬/uvicorn의 인바운드 연결을 막고 있을 수 있습니다 — 방화벽 알림이 뜨면
  "허용"을 선택하세요.

### `tailscale ip -4` 명령을 찾을 수 없다고 나옵니다

설치 후 터미널을 새로 열지 않았거나, PATH 반영 전일 수 있습니다. 터미널을 재시작하거나, 트레이
아이콘에서 IP를 직접 확인하세요.

### 회사/학교 네트워크에서 연결이 안 됩니다

일부 기관 네트워크는 VPN 트래픽을 차단합니다. Tailscale은 기본적으로 우회 경로(DERP 릴레이)를 자동
시도하지만, 방화벽 정책에 따라 완전히 막힐 수 있습니다. 이런 경우 다른 네트워크(모바일 데이터 등)에서
먼저 테스트해보세요.

### PC를 끄면 접속이 안 됩니다

Tailscale/웹 서버는 PC가 켜져 있고 프로그램이 실행 중일 때만 동작합니다. 24시간 접속이 필요하다면
AWS 등 상시 켜진 서버로 옮기는 것을 고려하세요 (추후 [docs/배포/](README.md)에 가이드 추가 예정).
