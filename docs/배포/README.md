# 배포 / 원격 접속 가이드

이 폴더는 **웹 클라이언트(`src/web/`)를 개인 PC 등에 로컬로 띄운 뒤, 외부(스마트폰·다른 컴퓨터 등)에서
접속하는 방법**을 다룹니다. "로컬 실행"만으로는 그 PC 앞에서만 화면을 볼 수 있는데, 외출 중에도
자동매매 상태를 확인하고 싶은 사람들을 위한 문서입니다.

## 왜 단순한 방법(Tailscale)부터인가

Traefik(리버스 프록시)이나 AWS(클라우드 서버) 같은 방법도 물론 가능하고, 실제로 이 폴더에 순서대로
추가할 예정입니다. 하지만 이 프로젝트의 본질은 **KB증권 OpenAPI를 활용한 자동매매로 수익을 내는 것**이지
네트워크·인프라 구축이 아닙니다. 인프라 공부에 며칠을 쓰는 것보다, 가장 단순하고 빠르게 "일단 외부에서
접속되는" 상태를 만들고 본업(전략 튜닝, 백테스트, 리스크 관리)에 시간을 쓰는 것이 우선순위라고 판단했습니다.

그래서 순서는 **쉬운 것 → 어려운 것**입니다:

| 방법 | 난이도 | 특징 | 상태 |
|---|---|---|---|
| **Tailscale** ([tailscale-원격접속.md](tailscale-원격접속.md)) | ⭐ 매우 쉬움 | 앱 설치 + 로그인만 하면 끝. 포트포워딩·공인IP·인증서 설정 불필요. 오직 내 기기끼리만 연결(사설망) | ✅ 문서 작성 완료 |
| Docker | ⭐⭐ 보통 | 실행 환경을 컨테이너로 고정 — 재현성·이식성 확보 | 🔜 추후 추가 예정 |
| Traefik / 리버스 프록시 | ⭐⭐⭐ 어려움 | 도메인·TLS 인증서·라우팅을 직접 구성, 여러 서비스를 한 서버에서 운영할 때 유리 | 🔜 추후 추가 예정 |
| AWS (클라우드 서버) | ⭐⭐⭐⭐ 어려움 | 24시간 운영, 집 PC를 꺼도 동작, 보안그룹·비용 관리 필요 | 🔜 추후 추가 예정 |

지금 당장 "핸드폰으로 내 컴퓨터의 자동매매 화면을 보고 싶다"가 목적이라면 **Tailscale**로 충분합니다.
Docker/Traefik/AWS는 "24시간 무중단으로 돌리고 싶다", "여러 서비스를 함께 운영하고 싶다" 같은 더 큰
요구가 생겼을 때 넘어가면 됩니다.

## AI를 활용하세요

네트워크·인프라 설정은 처음 해보면 낯설고, 방화벽/공유기 환경마다 화면이 조금씩 다를 수 있습니다.
막히는 단계가 있으면 **Claude Code 같은 AI 코딩 에이전트에게 에러 메시지나 상황을 그대로 붙여넣고
물어보는 것을 권장합니다** — 이 문서만으로 해결되지 않는 환경별 차이(회사망, 특정 공유기 설정 등)를
AI가 훨씬 빠르게 좁혀줄 수 있습니다. 설정을 완벽히 이해하고 손으로 다 하려 하기보다, AI와 함께
진행하는 편이 시간을 아낍니다.
