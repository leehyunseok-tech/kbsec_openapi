# 텔레그램 Agent 설정 가이드

텔레그램 Agent를 사용하려면 **텔레그램 봇 토큰**과 **Chat ID**가 필요합니다. 이 문서에서는 BotFather에 봇을 신청하는 과정부터 설정까지 단계별로 설명합니다.

---

## 1단계: 텔레그램 앱 설치 및 계정 만들기

1. **텔레그램 앱 다운로드**
   - 스마트폰: [Google Play](https://play.google.com/store/apps/details?id=org.telegram.messenger) (Android) 또는 [App Store](https://apps.apple.com/app/telegram-messenger/id686449807) (iOS)
   - 웹: https://web.telegram.org/ 또는 https://desktop.telegram.org/ (데스크톱 앱)

2. **계정 만들기**
   - 앱을 열고 휴대폰 번호로 가입합니다. (기존 계정이 있으면 건너뜁니다)

---

## 2단계: BotFather를 통해 봇 신청하기

텔레그램 봇은 **BotFather**라는 공식 봇을 통해서만 만들 수 있습니다.

### 2-1. BotFather 열기

아래 링크를 클릭하거나, 텔레그램 검색창에서 `@BotFather`를 검색합니다.

👉 **https://t.me/BotFather**

### 2-2. /newbot 명령어로 새 봇 만들기

BotFather 채팅창에서 다음을 입력합니다:

```
/newbot
```

또는 명령어 목록에서 `/newbot`을 선택합니다.

### 2-3. 봇 이름 정하기

BotFather가 다음과 같이 묻습니다:

```
Alright, a new bot. How are we going to call it? Please choose a name for your bot.
```

봇의 표시 이름을 입력합니다. (예: `KB증권 자동매매`)

> 💡 **참고**: 이것은 사람들이 보게 되는 이름이므로 자유롭게 지을 수 있습니다.

### 2-4. 봇 사용자명(Username) 정하기

BotFather가 다시 묻습니다:

```
Good. Now let's choose a username for your bot. It must be unique and end with the word "bot".
For example, TetrisBot or tetris_bot.
```

봇의 고유한 **사용자명**을 입력합니다. (예: `kbsec_auto_trading_bot`)

> ⚠️ **주의**: 사용자명은 다음 규칙을 따릅니다:
> - `_bot`으로 끝나야 합니다 (또는 `Bot`으로 끝남)
> - 고유해야 합니다 (다른 사람이 이미 사용하는 이름은 불가)
> - 영문자, 숫자, 언더스코어(_)만 사용 가능

### 2-5. 봇 토큰 받기

사용자명이 확인되면 BotFather가 **봇 토큰**을 보여줍니다:

```
Done! Congratulations on your new bot. You will find it at t.me/kbsec_auto_trading_bot.
You can now add a description, about section and profile picture for your bot, see /help for a list of commands.

Use this token to access the HTTP API:
1234567890:ABCDefGhIjKlMnOpQrStUvWxYz1234567890

For a description of the Bot API, see this page: https://core.telegram.org/bots/api
```

👇 **여기서 받은 숫자와 문자 조합이 `telegram_token`입니다.**

예:
```
1234567890:ABCDefGhIjKlMnOpQrStUvWxYz1234567890
```

> ⚠️ **보안 주의**: 이 토큰은 **절대 공개하지 마세요**. GitHub이나 블로그에 올리면 누구든 당신의 봇을 제어할 수 있습니다.

## 3단계: Chat ID 받기

Chat ID는 당신의 텔레그램 계정의 고유 번호입니다. 이를 통해 봇이 당신에게만 메시지를 보냅니다.

### 3-1. 봇과 대화 시작하기

2단계에서 만든 봇으로 이동합니다. (예: `https://t.me/kbsec_auto_trading_bot`)

또는 텔레그램에서 봇 사용자명을 검색해 찾습니다.

### 3-2. 봇에 시작 메시지 보내기

봇과 채팅창을 열고 `/start`를 보냅니다.

```
/start
```

### 3-3. Chat ID 확인하기

다음 URL을 **웹 브라우저에서 열어** Chat ID를 확인합니다:

```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
```

`<YOUR_BOT_TOKEN>`을 2단계에서 받은 토큰으로 바꿉니다.

예:
```
https://api.telegram.org/bot1234567890:ABCDefGhIjKlMnOpQrStUvWxYz1234567890/getUpdates
```

### 3-4. JSON 응답에서 Chat ID 찾기

브라우저에 JSON이 표시됩니다:

```json
{
  "ok": true,
  "result": [
    {
      "update_id": 123456789,
      "message": {
        "message_id": 1,
        "date": 1234567890,
        "chat": {
          "id": 987654321,
          "first_name": "Your Name",
          "type": "private"
        },
        "text": "/start",
        "entities": [...]
      }
    }
  ]
}
```

👇 **`"chat"` 아래의 `"id"` 값이 `telegram_chat_id`입니다.**

예:
```
987654321
```

> 💡 **참고**: 
> - 개인 채팅이면 양수입니다 (예: `987654321`)
> - 그룹 채팅이면 음수입니다 (예: `-987654321`)
> - 채팅이 없으면 `"result": []` (빈 배열)이 표시됩니다 → 다시 봇에 메시지를 보내고 새로고침하세요

## 4단계: config.py에 설정하기

1. 프로젝트 폴더에서 `config/config.py`를 열거나 만듭니다.
   - 없으면 `config/config.example.py`를 복사해 `config/config.py`를 만듭니다.

2. 아래 부분을 찾아 값을 입력합니다:

```python
# 2단계에서 받은 봇 토큰
telegram_token = "1234567890:ABCDefGhIjKlMnOpQrStUvWxYz1234567890"

# 3단계에서 확인한 Chat ID
telegram_chat_id = "987654321"
```

> ⚠️ **보안 주의**: `config.py`는 `.gitignore`에 의해 GitHub에 올라가지 않습니다. 절대 공개 저장소에 커밋하지 마세요.

---

## 5단계: 텔레그램 Agent 실행하기

설정이 완료되면 다음 명령어로 텔레그램 Agent를 실행할 수 있습니다:

### Windows
```bash
run-kbsec-openapi.bat telegram
# 또는
manage\run\run-telegram.bat
```

### macOS / Linux
```bash
./run-kbsec-openapi.sh telegram
# 또는
./manage/run/run-telegram.sh
```

실행 후 설정한 Chat ID로 메시지가 도착하면 성공입니다!

---

## 참고: 여러 사용자에게 메시지 보내기

혼자가 아닌 여러 사람에게 메시지를 보내고 싶다면 **그룹**을 사용합니다:

1. 텔레그램에서 **새 그룹** 만들기
2. 만든 봇을 그룹에 초대
3. 그룹에서 `/start` 보내기
4. 3단계와 동일하게 Chat ID 확인 (이번엔 음수)

## 문제 해결

### 토큰을 잘못 입력했다면?

BotFather로 돌아가 `/mybots`를 입력해 만든 봇 목록을 확인하고, 봇을 선택해 `/revoke`로 토큰을 재발급받을 수 있습니다.

### getUpdates에서 빈 배열이 나온다면?

- 봇과 채팅을 아직 시작하지 않았을 가능성: 다시 한 번 `/start` 보내기
- 토큰이 잘못되었을 가능성: URL에서 토큰 다시 확인

### 그룹에서 Chat ID를 확인했는데 봇이 메시지를 받지 못한다면?

- 그룹에 봇을 **admin**으로 추가해 **메시지 읽기 권한** 부여
- 또는 개인 채팅(1:1)으로 테스트해보기
