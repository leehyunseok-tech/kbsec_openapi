# KB증권 자동매매 Agent - 명령어 가이드

이 문서는 AI 에이전트(`src/utils/ai_command_converter.py`)가 사용자의 자연어 지시사항을
명령어로 변환하기 위해 **런타임에 그대로 참조하는** 문서입니다. 단순 설명서가 아니라
실제 동작에 쓰이는 규칙 정의서이므로, 명령어를 추가·변경·삭제할 때는 반드시 이 문서도
함께 갱신해야 합니다 (`CLAUDE.md`의 필수 규칙 참고).

---

## 기본 규칙

- 이 문서 안의 모든 "명령어" 표기(`buy 005930 10` 등)는 **당신(AI)이 반환할 JSON 배열
  안의 문자열 형식**이며 `/`를 붙이지 않습니다. 사용자가 채팅에 직접 `/`로 명령을
  입력한 경우(예: `/buy 005930 10`)는 애초에 AI를 거치지 않고 곧바로 실행되므로
  당신에게 전달되지 않습니다 — 당신에게 오는 입력은 언제나 `/` 없는 자연어입니다.
- 국내 종목코드는 반드시 **6자리 숫자** 문자열입니다. 예: `005930`(삼성전자), `000660`(SK하이닉스)
- 수량·금액·가격은 모두 **양의 정수**입니다.
- 퍼센티지(익절/손절/트레일링)는 소수 포함 숫자 가능합니다. 예: `3.5`
- 로그인이 필요한 명령을 실행하려면 먼저 `login real`을 사용해야 합니다.
- KB증권 개발환경(모의투자)은 아직 제공되지 않습니다 — `dev` 관련 명령은 절대 제안하지 마세요.
  모든 로그인/거래는 운영환경(실거래) 기준입니다.
- `buy`/`sell`/`srch`/`investor` 명령에서 사용자가 종목명으로 말한 경우, **종목코드를 직접
  추측하지 말고 종목명을 그대로 사용**하세요 (예: `buy 삼성전자 10`, `srch SK하이닉스`).
  실제 종목코드 변환은 로컬 종목마스터 파일(`mst/api/`)로 별도 처리되어 정확도가 더
  높습니다. 사용자가 이미 6자리 종목코드로 말했다면 그 코드를 그대로 사용하세요.
  단, `rsv`에 중첩되는 명령(예: "매일 10시에 삼성전자 5주 사줘")은 예외적으로 지금까지처럼
  직접 종목코드로 변환하세요 — 예약 명령은 재실행 시 이 변환 단계를 거치지 않습니다.
- **`buy`/`sell`/`srch`는 국내 종목뿐 아니라 미국 주식(나스닥/뉴욕/아멕스 상장)도 지원합니다.**
  IONQ, 아이온큐, ionq처럼 티커든 한글명이든 영문명이든 대소문자·표기와 무관하게
  **그대로** 사용하세요 — "이 Agent는 국내 종목만 지원한다"고 판단해서 빈 배열을 반환하거나
  거부 사유를 설명하지 마세요. 실존 여부·정확한 티커 확인도 당신이 할 일이 아닙니다
  (로컬 종목마스터가 국내에서 못 찾으면 자동으로 해외까지 검색합니다). 예:
  "아이온큐 10주 사줘" → `buy 아이온큐 10`, "IONQ 5주 팔아줘" → `sell IONQ 5`,
  "IONQ 주가 알려줘" → `srch IONQ`.
  단, `investor`(투자자별 매매)는 KB API에 해외 버전이 없어 국내 전용입니다 — 국내
  6자리 코드/종목명만 다루고, 해외 종목이 오면 "국내 종목만 지원한다"고 명확히 답하세요.
  또한 해외 `sell`은 보유수량을 KB가 조회해주는 API가 없어 **수량을 반드시 포함**해야
  합니다 — "아이온큐 다 팔아줘"처럼 수량 없이 전량 매도를 요청하면 명령을 만들지 말고
  빈 배열을 반환하세요(국내는 수량 생략 시 보유 전량이 매도되니 문제 없음).
- KB증권 API 목록에는 조건검색식 실시간거래(jggs/cond), VI감시(vi), 테마분석(theme),
  공매도분석(short/loan)에 대응하는 API가 없어 이 Agent에서는 지원하지 않습니다.
- `api`(하단 "API 직접호출" 절 참고)는 `docs/api/md`에 문서화된 API를 한글 이름으로
  직접 실행하는 **조회 전용** 통로입니다. 매수/매도/취소/정정 등 실제 주문 의도가
  있으면 절대 `api`로 만들지 말고 반드시 `buy`/`sell`/`ccl`을 사용하세요.

## 1. 인증 및 상태

### `login`
KB증권 OAuth2 접근토큰을 발급받아 거래를 시작합니다. (개발환경/모의투자는 KB증권에서
아직 제공하지 않아 운영환경만 사용 가능합니다.)

| 사용법 | 설명 |
|--------|------|
| `login real` | 운영환경(실전)으로 로그인 |

**자연어 → 명령어 예시**
- "로그인해줘" → `login real`
- "실거래 로그인" → `login real`

### `status`
현재 로그인 상태를 확인합니다.

```
status
```

## 2. 조회

### `srch`
특정 종목의 현재가, 등락률, 거래량, PER/PBR 등 기본 정보를 조회합니다. **국내 + 미국 주식 모두 지원.**

```
srch {종목코드}
```

**자연어 → 명령어 예시**
- "삼성전자 주가 알려줘" → `srch 삼성전자`
- "SK하이닉스 현재가" → `srch SK하이닉스`
- "아이온큐 주가 얼마야" → `srch 아이온큐`

---

### `rank`
상위 종목 랭킹을 조회합니다.

| 사용법 | 설명 |
|--------|------|
| `rank` | 메뉴 표시 |
| `rank 1` | 거래대금상위 Top 20 |
| `rank 2` | 등락률상위 Top 20 |
| `rank 3` | 거래량상위 Top 20 |
| `rank 4` | 업종랭킹 |

**자연어 → 명령어 예시**
- "거래대금 많은 종목 보여줘" → `rank 1`
- "오늘 많이 오른 종목" → `rank 2`

---

### `report` / `r`
보유종목 현황과 미체결 주문을 조회합니다.

```
report
```

---

### `mst`, `stcd`
종목마스터 현황 조회 및 종목명 키워드 검색 (로컬 파일 기반, API 호출 없음).

| 사용법 | 설명 |
|--------|------|
| `mst` | 종목마스터 로드 현황 |
| `stcd {키워드}` | 종목명 검색 (예: `stcd 삼성`). 국내는 종목코드로도 검색됨(예: `stcd 005930`) |
| `stcd {키워드1} {키워드2}` | 여러 키워드 OR 검색 |

**자연어 → 명령어 예시**
- "카카오 종목코드 찾아줘" → `stcd 카카오`

---

### `api` — API 직접호출 (조회 전용)
`docs/api/md`에 문서화된 KB증권 API 74개를 코드를 몰라도 **API 명세의 한글 이름**으로
바로 실행합니다. 파일명이 `SSQM1801-보유주식 조회-...md`라면 이름은 "보유주식 조회"이고,
공백 유무는 무시해도 됩니다("보유주식조회"로 말해도 동일하게 인식됩니다).

| 사용법 | 설명 |
|--------|------|
| `api {API 한글이름}` | 해당 API 실행 (예: `api 보유주식조회`, `api 예수금내역`) |

- **코드를 절대 추측하지 말고 API 한글 이름을 그대로 사용하세요** — buy/sell의 종목명과
  동일한 이유로, 실제 코드 변환은 로컬에서 `docs/api/api-list.json`으로 결정적으로
  처리됩니다(이름이 여러 API와 겹치면 사용자에게 번호 선택을 요청하는 절차가 자동으로
  진행됩니다. 예: "현재가"는 국내(`IVU10140`)/해외(`GSS10030`) 각각 존재).
- **주문/취소/정정 계열 API**(매수주문, 매도주문, 정정주문, 취소주문 등)는 실행 전 추가
  선택이 필요해 이 경로로는 절대 자동 실행되지 않고 "/api {코드}로 직접 실행하세요"라는
  안내만 표시됩니다 — 애초에 이 명령으로 주문을 시도하지 마세요.
- 사용자가 특정 API를 이름으로 콕 집어 조회를 요청할 때만 사용하세요. "삼성전자 주가
  알려줘"처럼 이미 전용 명령(`srch`)이 있는 요청에는 `api`를 쓰지 말고 그 명령을
  쓰세요 — `api`는 전용 명령이 없는 나머지 조회 API(예수금내역, 매매정산현황, 세계지수,
  환율종합, 증시주변자금동향 등)를 위한 보조 경로입니다.

**자연어 → 명령어 예시**
- "보유주식조회 해줘" → `api 보유주식조회`
- "예수금내역 알려줘" → `api 예수금내역`
- "환율종합 보여줘" → `api 환율종합`
- "매매정산현황 확인해줘" → `api 매매정산현황`

## 3. 매매

### `buy`
종목을 매수합니다. **국내(6자리 코드) + 미국 주식(티커) 모두 지원.**

| 사용법 | 설명 |
|--------|------|
| `buy {종목코드} {수량}` | 시장가 매수 (미국은 현재가 조회 후 지정가로 제출) |
| `buy {종목코드} {수량} {지정가}` | 지정가 매수 |
| `buy {종목코드} max {금액}` | 금액 범위 내 최대 수량 매수 (국내: 원화, 미국: USD) |

**자연어 → 명령어 예시**
- "삼성전자 10주 사줘" → `buy 삼성전자 10`
- "삼성전자 100만원어치 사줘" → `buy 삼성전자 max 1000000`
- "SK하이닉스 5주 15만원에 사줘" → `buy SK하이닉스 5 150000`
- "아이온큐 10주 사줘" → `buy 아이온큐 10` (미국 나스닥 상장이어도 그대로 진행)
- "IONQ 100달러어치 사줘" → `buy IONQ max 100`

---

### `sell`
종목을 매도합니다. **국내(6자리 코드) + 미국 주식(티커) 모두 지원.** 단, 미국 주식은
보유수량 자동조회가 안 되므로 수량을 반드시 함께 말해야 합니다(`sell all`/전량 매도는
국내 전용).

| 사용법 | 설명 |
|--------|------|
| `sell all` | 보유 전체 종목 시장가 매도 (국내만) |
| `sell {종목코드}` | 전량 매도 (국내만, 시장가) |
| `sell {종목코드} {수량}` | 수량 지정 매도 (미국은 현재가 조회 후 지정가로 제출) |
| `sell {종목코드} {수량} {지정가}` | 지정가 매도 |

**자연어 → 명령어 예시**
- "전부 다 팔아줘" → `sell all`
- "아이온큐 5주 팔아줘" → `sell 아이온큐 5`
- "삼성전자 팔아줘" → `sell 삼성전자`
- "삼성전자 5주만 팔아줘" → `sell 삼성전자 5`

---

**자연어 → 명령어 예시**
- "미체결 주문 다 취소해줘" → `ccl pend`

## 4. 설정

### `mkhr` — 장 시간
| 사용법 | 설명 |
|--------|------|
| `mkhr` | 현재 장 시간 조회 |
| `mkhr {시작} {종료}` | 장 시간 설정 (예: `mkhr 9:30 15:00`) |

### `익절` / `손절`
| 사용법 | 설명 |
|--------|------|
| `익절` | 현재 익절 기준 조회 |
| `익절 {퍼센티지}` | 익절 기준 설정 (예: `익절 5`) |
| `손절` | 현재 손절 기준 조회 |
| `손절 {퍼센티지}` | 손절 기준 설정 |

**자연어 → 명령어 예시**
- "익절 5퍼로 설정" → `익절 5`
- "손절 10프로로 해줘" → `손절 10`

### `time` — 미체결 주문 타임아웃
```
time {초} cancel   (s초 후 취소)
time {초} market   (s초마다 호가 한 칸 올려 재주문)
time 0 cancel      (비활성화)
```

### `cooldown` — 재매수 금지 시간
```
cooldown {시간}   (매도 후 N시간 재매수 금지)
cooldown 0        (제한 없음)
```

### `blacklist` — 매매 금지 종목
```
blacklist add {종목코드}
blacklist list
blacklist remove {번호}
```

### `mxhold` — 최대 보유 종목 수
```
mxhold {개수}
mxhold 0   (제한 없음)
```

### `stts`
전체 설정값을 한 번에 조회합니다.
```
stts
```

## 5. 예약 / 기록

### `rsv`
| 사용법 | 설명 |
|--------|------|
| `rsv {시간} {명령어}` | 매일 평일 반복 예약 |
| `rsv once {시간} {명령어}` | 한 번만 예약 |
| `rsv list` | 예약 목록 조회 |
| `rsv remove {번호}` / `rsv remove all` | 예약 삭제 |

**자연어 → 명령어 예시**
- "매일 10시에 삼성전자 5주 사줘" → `rsv 10:00 buy 005930 5`
- "오늘 3시 반에 삼성전자 팔아줘" → `rsv once 15:30 sell 005930`

### `log`, `anss`
| 사용법 | 설명 |
|--------|------|
| `log` | 오늘 체결 내역 CSV 파일 전송 |
| `log {일수}` | N일 전 체결 내역 CSV 전송 |
| `anss` | 오늘 체결 내역 AI 분석 |
| `anss {일수}` | 최근 N일 체결 내역 AI 분석 (최대 30일) |
