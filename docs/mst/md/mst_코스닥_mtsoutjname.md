## 사용 예시 (Python)

```python
import pandas as pd

# 마스터 파일 읽기
columns = ['종목코드', '종목명', '매매수량단위코드', '결제단위코드', '예탁결제원증거금율',
           '관리종목여부', '거래정지여부', '감리종목여부', '신용가능여부', '투자위험예고여부',
           '시장구분', '시장경보구분', 'ETF여부', 'ETN여부', 'ELW여부',
           '스팩여부', '리츠여부', '인프라펀드여부', '기타여부', '불성실공시여부',
           '주문유형', 'K200여부', 'KRX300여부', '코스닥150여부', '중형주여부',
           '대형주여부', '시가총액', '정리매매여부']

df = pd.read_csv('mtsoutjname.mst', sep='|', names=columns, encoding='euc-kr')

# 관리종목 제외, 거래정지 제외
tradable = df[(df['관리종목여부'] == 'N') & (df['거래정지여부'] == 'N')]

# 시가총액 상위 종목
top_by_cap = tradable.sort_values('시가총액', ascending=False).head(20)

print(f"전체 종목 수: {len(df)}")
print(f"거래 가능 종목 수: {len(tradable)}")
```

## AI 활용 가이드

- **종목 검색**: 종목코드(1번) 또는 종목명(2번) 필드 사용
- **거래 가능 여부**: 관리종목여부(6), 거래정지여부(7) 확인
- **신용거래 가능**: 신용가능여부(9) 필드 확인
- **시가총액 정렬**: 시가총액(27) 필드 사용
- **지수 구성종목**: 코스닥150여부(24), KRX300여부(23) 필드 활용
