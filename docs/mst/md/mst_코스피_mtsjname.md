## 사용 예시 (Python)

```python
import pandas as pd

# 마스터 파일 읽기
columns = ['종목코드', '종목명', '관리종목여부', '종목구분', '감리종목여부',
           '거래정지여부', '투자위험예고여부', '불성실공시여부', '업종코드', '시장구분',
           '시장경보구분', '매매수량단위코드', '결제단위코드', '예탁결제원증거금율', '신용가능여부',
           '신용증거금율', '예비1', '예비2', 'ETF여부', 'ETN여부',
           'ELW여부', '스팩여부', '리츠여부', '인프라펀드여부', '기타여부',
           '주문유형', 'K200여부', 'KRX300여부', '코스피100여부', '코스피50여부',
           '대형주여부', '예비3', '시가총액', '정리매매여부']

df = pd.read_csv('mtsjname.mst', sep='|', names=columns, encoding='euc-kr')

# 일반 주식만 필터링
stocks = df[df['종목구분'] == 'ST']

# 거래정지 종목 제외
tradable = stocks[stocks['거래정지여부'] == 'N']

print(f"전체 종목 수: {len(df)}")
print(f"일반 주식 수: {len(stocks)}")
print(f"거래 가능 종목 수: {len(tradable)}")
```

## AI 활용 가이드

- **종목 검색**: 종목코드(1번) 또는 종목명(2번) 필드 사용
- **거래 가능 여부**: 관리종목여부(3), 거래정지여부(6) 확인
- **종목 유형 분류**: 종목구분(4) 필드로 주식/ETF/ETN/ELW 구분
- **시가총액 정렬**: 시가총액(33) 필드 사용
- **지수 구성종목**: K200여부(27), KRX300여부(28) 필드 활용
