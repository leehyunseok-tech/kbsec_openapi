## 사용 예시 (Python)

```python
import pandas as pd

# 마스터 파일 읽기
columns = ['거래소코드', '종목코드', '종목명_한글', '종목명_영문', '국가코드',
           '통화코드', 'ISIN코드', '거래정지여부', '시장구분', '거래가능여부',
           '업종코드', 'ETF여부', 'ADR여부', '매수가능여부', '매도가능여부',
           '예비1', '예비2', '예비3', '전일종가', '호가단위_기본',
           '호가단위_상세', '예비4', '예비5', '예비6', '소수점매매가능'] + [f'예비{i}' for i in range(7, 18)]

df = pd.read_csv('FORENMST_US.MST', sep='|', names=columns, encoding='euc-kr')

# 나스닥 종목만 필터링
nasdaq = df[df['거래소코드'] == 'NAS']

# 거래 가능 종목만
tradable = df[(df['거래정지여부'] == 0) & (df['거래가능여부'] == 1)]

# ETF 목록
etf_list = df[df['ETF여부'] == 1]

# ADR 목록
adr_list = df[df['ADR여부'] == 1]

print(f"전체 종목 수: {len(df)}")
print(f"나스닥 종목 수: {len(nasdaq)}")
print(f"거래 가능 종목 수: {len(tradable)}")
print(f"ETF 종목 수: {len(etf_list)}")
print(f"ADR 종목 수: {len(adr_list)}")
```

## API 연동 시 참고사항

해외주식 API 호출 시 필요한 파라미터:

| API 파라미터 | 마스터 필드 | 설명 |
|-------------|-------------|------|
| `krx_cd` | 거래소코드(1) | NAS, NYS, AMS |
| `is_cd` | 종목코드(2) | 티커 심볼 |

### 예시: 현재가 조회

```json
{
  "dataBody": {
    "krx_cd": "NAS",
    "is_cd": "NVDA"
  }
}
```

## AI 활용 가이드

- **종목 검색**: 종목코드(2), 종목명_한글(3), 종목명_영문(4) 필드 사용
- **거래소 구분**: 거래소코드(1) 필드로 NAS/NYS/AMS 구분
- **거래 가능 여부**: 거래정지여부(8)=0, 거래가능여부(10)=1 확인
- **ETF/ADR 구분**: ETF여부(12), ADR여부(13) 필드 활용
- **업종 분류**: 업종코드(11) 필드로 섹터 분류
