실행 API 명세 설정

접속 설정

· KB증권 홈페이지 (고객서비스->Opne API->Open API 신청/조회) 에서 발급받은 앱키/앱시크릿을 입력하고 저장하면 즉시 로그인됩니다.
· 입력한 키는 서버 메모리에만 보관되며 파일로 저장되지 않습니다. 서버가 재시작되면 다시 입력해야 합니다.
· 선택 항목(Claude/텔레그램)은 비워둬도 됩니다 — 자연어 명령을 쓰려면 Claude API 키가 필요합니다.

⚠️ KB증권은 아직 개발환경(모의투자)을 제공하지 않아 운영환경(실거래)만 사용 가능합니다. 실제 계좌로 주문이 나갈 수 있으니 주의하세요.
