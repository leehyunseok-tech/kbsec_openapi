요청 본문 (dataBody)

명세의 INPUT 파라미터가 기본값으로 채워져 있습니다 — 값을 수정한 뒤 전송을 누르면 실제 KB API로 호출됩니다. dataHeader(ipAddr/macAddr)는 일반 주문/조회와 동일하게 서버가 자동으로 채웁니다.

⚠️ 주문 계열 API입니다 — 운영환경(실거래)이므로 전송하면 실제 주문이 나갑니다.
