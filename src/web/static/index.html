사용 방법

· 설정에 앱키/앱시크릿 저장시 자동 토큰발급.
· /명령어 + [Enter] 즉시 실행
· 자연어 입력 + [Enter] AI가 명령어로 바꿔준 뒤 실행 (Claude API 키 설정 필요).
· 예시 명령 클릭시 명령창에 입력
· 설명 추가 예정( 추가 API 적용시 )

조회 /srch 005930 /report /rank /stcd 삼성
매매 /buy 005930 10 /sell 005930 /ccl pend
자연어 (AI) 삼성전자 10주 사줘 보유주식 전부 팔아줘 보유주식조회 해줘
설정/자동매매 /stts /익절 5 /start trst /stop trst
API 직접호출 /api list 주문 /api SSQM1801 /info SSAM1801
기타 /help /status /log
